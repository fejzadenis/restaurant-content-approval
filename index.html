Content approval gate — clickable demo

The rule: an approval only counts for the revision it was given for. Edit the caption after approval and the approval stops counting, because editing bumps the revision. The client-facing links below are real HMAC tokens verified in your browser by the same approval-core.js that runs inside the n8n workflows. State is in memory here; in production the three SQL tables hold it.

  • The old link is refused as stale
  • Publish is blocked for revision 2
  • Send revision 2
  • Client approves revision 2
  • Publish succeeds; a second publish is refused
